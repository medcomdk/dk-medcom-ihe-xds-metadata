# Metadata for CDA Document

This implementation guide includes profiles of the DocumentReference resources correlated to the individual MedCom standards. The intension of this IG is to gather all general constraints in regards to metadata.

## Maping from XDS metadata to FHIR Document Reference resource

The mapping is based on [HL7's mapping between XDS metadata to FHIR DocumentReference resource](https://www.hl7.org/fhir/documentreference-mappings.html#xds) and [IHE MHD - Mobile access to Health Documents](https://profiles.ihe.net/ITI/MHD/StructureDefinition-IHE.MHD.Minimal.DocumentReference-mappings.html). These restrictions are also defined in the profile, which can be found under the tab 'Artifacts'.

## CodeSystems and ValueSets
More information about MedCom XDS metadata ValueSets can be found in the [Terminology for XDS Metadata IG](https://medcomfhir.dk/ig/xdsmetadata/).
